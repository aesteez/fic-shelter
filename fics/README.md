# Put fics here

Drag the **HTML** or **EPUB** files you downloaded from AO3 into this folder
(**Add file → Upload files**), then press **Commit changes**.
The site rebuilds itself in 1–2 minutes.

- Keep the files as AO3 made them: the author, tags and link are read from them.
- PDF, MOBI and AZW3 files can't be read.
- Fics with the "Underage" warning are skipped.
- You can make subfolders (for example one per fandom) if you like.
